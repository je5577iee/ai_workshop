    上機一的字典法怎麼算
    
      
      
        
    1. 斷詞：用瀏覽器內建的中文斷詞功能（JavaScript 的 Intl.Segmenter，語言設定為繁體中文）把句子切成詞。
      2. 
        
    2. 查表：每個詞拿去 NTUSD 查，詞要完全相同才算。在正面清單 +1，在負面清單 −1，不在清單裡 0 分。同時出現在兩份清單的詞不計分。
      3. 
        
    3. 加總：總分大於 0 判正面，小於 0 判負面，等於 0 判中性。
      4. 
      
    
      
    NTUSD 本身只分正面和負面，沒有分數，±1 與判斷規則是本網頁為了教學設定的。瀏覽器內建斷詞的準確度不如 CKIP、jieba 等專門工具，不同瀏覽器切出來的結果也可能略有不同。若瀏覽器不支援內建斷詞，會改用正向最大匹配（直接在句子中找字典裡的詞，長的詞優先）。
    
    
    

    
    
      
    AI 分析結果
    
      
    上機二、上機三中「AI 的答案」是事先用 Claude（Anthropic）分析後放進網頁的，不是即時產生。上機三的每則評論可以有多個主題，每個主題各自標上正面、中性或負面（面向情感分析）。AI 的判斷不一定正確，僅供課堂比較使用。
    
    
    

    
    
      
    評論資料
    
      
    上機二：取自 Google 地圖上多家麥當勞分店的公開評論，混合不同分店，並已移除留言者姓名、頭像等資訊，僅供課堂教學使用。
    
      
    上機三：飯店、手搖飲店、電影院三份資料，取自 Google 地圖上多家店的公開評論，混合不同店家，內容經節錄，部分文字略有修改，並已移除留言者資訊。每份另外加入約 9 則講者編寫的教學用資料（太短的評論、重複貼文、網址、標籤、廣告），用來練習資料清理。
